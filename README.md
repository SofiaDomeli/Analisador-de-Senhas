
# Analisador de senhas
![Logo](https://th.bing.com/th/id/OIP.gTHWGcaPQnJpubYJh2eV1QAAAA?w=313&h=313&rs=1&pid=ImgDetMain)

## Objetivo
Esse projeto avalia se a sua senha está de acordo com os padrões certos. Alguns desses requisitos são: a senha deve ter pelo menos 8 caracteres, deve conter pelo menos uma letra minúscula e uma maiúscula e deve ter caracteres especiais. Esse projeto tem o objetivo de realizar a prática de devOps.

## Funcionalidades
 
- Verificar senhas;
- Programa interativo. Você pode digitar senhas no terminal;

## Instalação

Inicie um repositório Git na sua máquina e siga os seguintes passos quando 
```bash
    git init 
    git remote add origin //github.com/SofiaDomeli/Analisador-de-Senhas.git
    git clone https://github.com/SofiaDomeli/Analisador-de-Senhas.git
```
Para rodar o projeto, precisará do python instalado em seu computador:
https://www.python.org/downloads/

Tudo pronto! Agora é só abrir seu repositório e depois clicar no arquivo "criadorDeSenhas.py":
